\section*{Thesis experimental grid --- what to actually test (2 phases)}

\subsection*{Phase 00 --- Feature-vector construction (best vector per signal, via paraconsistent EPC)}

Goal: for \textbf{voice} and for \textbf{EEG} separately, find the feature-extraction method that
maximizes paraconsistent separability ($D_{\text{truth}}$ minimal), before any classifier sees the data
(ch08 \S estruturaDaEstrategiaProposta).

Candidates per signal (voice, EEG each get their own ranking --- fused vectors are built \emph{after}
this phase, from each side's winning vector):
\begin{itemize}
    \item \textbf{Handcrafted}, swept over \emph{mother wavelet} $\times$ \emph{scale}:
    \begin{itemize}
        \item wavelet: 23 options (\texttt{haar} + \texttt{daub4}\dots\texttt{daub46})
        \item scale: bark, mel, lfcc; and \texttt{cepstral} (bool): false = Categoria 1 (band energies), true = Categoria 2 (log+DCT-II → LFCC/MFCC/BFCC)
    \end{itemize}
    each carrying the descriptor set: energy, ZCR, entropy, Teager--Kaiser, jitter, shimmer.
    So $23 \times 3 = 69$ handcrafted variants per signal.
    \item \textbf{Autoencoder} --- 12 compact AEs per signal: 9 SNN-AE (spiking; 3 sizes $\times$ 3 temporal encodings --- poisson/latency/direct) and 3 ANN-AE (dense; 3 sizes), latent 8/16/32, 2:1 hidden.
\end{itemize}

So the \emph{implemented} Phase 00 grid $=$ 2 signals $\times$ (69 handcrafted $+$ 12 autoencoder)
$=$ \textbf{162 rankings}, each scored by $\alpha,\beta,G_1,G_2,D_{\text{truth}}$
(\autoref{sec:conceitos}). Output of this phase: one winning feature vector for voice, one for EEG.
The 12 autoencoders per signal are compact single-layer SNN-AEs (poisson/latency/direct $\times$ 3 sizes)
and ANN-AEs (3 sizes), both families wired; the Categoria-2 cepstral handcrafted variants are also
implemented. SNN-AE spike frames use temporal integration (state reset once per sample, then
integrated over \texttt{time\_steps}=16 frames, mean-latent readout) and a lowered encoder firing
threshold (\texttt{voltage\_threshold}=0.2 for poisson/latency; the LIF default 1.0 for direct, which
reproduces the un-encoded baseline). Measured on tiny/EEG: poisson $\alpha=0.069$, latency
$\alpha=0.258$, direct $\alpha=0.875$ (near coin-flip) --- confirming temporal coding is what makes the
SNN-AE separable at all.

\subsection*{Phase 01 --- Authentication (DSNN classification, biometric ablation)}

Goal: feed \textbf{only Phase 00's single winning combination} (the wavelet$\times$scale or
autoencoder chosen by the paraconsistent ranking) into the \textbf{DSNN} (deep residual spiking
classifier, thesis-only --- the plain RNN/ResNet classifier is Guayaquil-paper-only, ch08 \S82) and
measure biometric verification performance under 4 signal-source modes, to isolate each source's
contribution (ch08 \S32):

\begin{enumerate}
    \item[00a] \textbf{voz + EEG, fusão precoce} (\texttt{fused-early}) --- raw voice+EEG concatenated before one extraction pass
    \item[00b] \textbf{voz + EEG, fusão tardia} (\texttt{fused-late}) --- per-signal extraction, feature vectors concatenated after (audit C12)
    \item[01] \textbf{apenas voz (fonada)} --- ablation, voice vector only
    \item[02] \textbf{apenas EEG (imaginada)} --- ablation, EEG vector only
\end{enumerate}

Each of these 4 source modes is additionally crossed with 2 axes explicitly required by the thesis's
own research questions / metrics section:

\begin{itemize}
    \item \textbf{text-dependent vs.\ text-independent} (ch06, Questão 4): same phrase spoken+imagined
    vs.\ arbitrary/mismatched phrase between train and test. Tests whether extraction-method
    performance is text-sensitive.
    \item \textbf{CV scheme}: nested 5-fold (unbiased hyperparameter selection) vs.\ flat grouped
    5-fold. Both are speaker-disjoint (verification protocol, ch08 \S71) --- test speakers never
    appear in training.
\end{itemize}

So Phase 01 grid $=$ 4 source modes $\times$ 2 (dependent/independent) $\times$ 2 (nested/flat)
$=$ \textbf{16 DSNN runs}, all using the single Phase-00 winning combination (the extractor axis is
\emph{not} swept in Phase 01 --- the paraconsistent ranking already picked it). The shipped
\texttt{phase01/} profiles carry a placeholder \texttt{feature\_extraction} block to be replaced with
that winner before running.

\textbf{Primary metrics} (ch08 \S71, verification protocol): EER and AUC. Closed-set metrics
(accuracy/F1/precision/recall/specificity) only reported if a closed-set evaluation is also run
alongside verification --- not the main claim. MSE is reconstruction-only (autoencoder training), not
a classification metric.

\subsection*{Observations / things easy to forget}

\begin{itemize}
    \item \textbf{Paired loading invariant}: the loader always pulls both audio+EEG per trial
    (via \texttt{eeg\_index}); the \texttt{modality} field only selects what feeds extraction. This
    guarantees voice-only / EEG-only / fused runs share the \emph{exact same} subject/trial set ---
    otherwise the 3-mode ablation in Phase 01 would not be a fair comparison.
    \item \textbf{Regularization is a training-config axis, not a method-combination axis} --- but it
    must stay fixed (or itself be swept and reported) across Phase 01 runs to keep comparisons fair:
    decoupled L2 weight decay (AdamW-style, spares biophysical $R,C,V_{th}$) and firing-rate
    regularization (DSNN-only, keeps spike rate in $[0.05, 0.80]$, prevents dead/saturated neurons).
    \item \textbf{Threshold-Dependent Batch Normalization (tdBN)} --- DSNN-only, stabilizes deep
    spiking net training; also a fixed/swept training config, not a feature-extraction combination.
    \item \textbf{Data leakage / input normalization} (audit G1, implemented): per-feature z-score
    standardization of the classifier input, statistics fit on each fold's training rows only and
    applied to train+test (\texttt{E05Classifiers.cpp}, \texttt{training.standardize\_features},
    default on). Prevents test-set leakage. Matches ch07 \S normalizacaoEntrada.
    \item \textbf{Pre-emphasis} ($\alpha=0.97$) applies to audio-derived vectors only, before energy/
    spectral computation --- relevant to every voice-involving combo in both phases (fused included).
    \item \textbf{LSTM-AE and plain RNN/ResNet classifier are out of thesis scope} --- they exist in
    the Experiment05 code because both papers (Guayaquil congress) share the same pipeline, but are
    not part of either phase's combination grid above.
\end{itemize}
