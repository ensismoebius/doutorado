# 10.1117 Loader Robustness Tests

This directory contains robustness tests for the 10.1117 EEG/Audio MAT loaders:

- Property-based tests (GoogleTest):
  - `eeg_loader_property_tests.cpp`
  - `audio_loader_property_tests.cpp`
- Fuzz targets (libFuzzer):
  - `fuzz_eeg_loader.cpp`
  - `fuzz_audio_loader.cpp`

All invariants are checked against `nn::data_loaders::ImaginedSpeechSchema_10_1117`.

## Property-Based Tests

Property tests are compiled into `data_loaders_10_1117_gtest`.

Run only property tests:

```bash
ctest --test-dir build -R "PropertyTest" --output-on-failure
```

## Build Fuzz Targets

Fuzz targets are opt-in and require Clang.

Configure (example):

```bash
cmake -S . -B build-fuzz \
  -DCMAKE_CXX_COMPILER=clang++ \
  -DNN_ENABLE_FUZZING=ON
```

Build fuzz executables:

```bash
cmake --build build-fuzz --target fuzz_eeg_loader fuzz_audio_loader -j$(nproc)
```

Sanitizers are enabled by target flags:

- `-fsanitize=fuzzer,address,undefined`
- `-fno-omit-frame-pointer`

## Run Fuzzers

Create corpus directories:

```bash
mkdir -p fuzz-corpus/eeg fuzz-corpus/audio fuzz-artifacts
```

Run EEG loader fuzzer:

```bash
./build-fuzz/src/core/data_loaders/10.1117/tests/fuzz/fuzz_eeg_loader \
  -max_total_time=60 \
  -artifact_prefix=fuzz-artifacts/ \
  fuzz-corpus/eeg
```

Run audio loader fuzzer:

```bash
./build-fuzz/src/core/data_loaders/10.1117/tests/fuzz/fuzz_audio_loader \
  -max_total_time=60 \
  -artifact_prefix=fuzz-artifacts/ \
  fuzz-corpus/audio
```

## Seed Corpus Recommendations

Start with a few valid `.mat` samples generated by
`MockImaginedSpeechDatasetGenerator`, then add adversarial seeds such as:

- wrong column count
- missing labels
- wrong channel count
- wrong audio signal length
- truncated files
- random byte payloads

This improves mutation quality and coverage of loader error paths.
