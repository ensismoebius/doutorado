# nn — the C++20 framework and every experiment

A neural-network framework written for this PhD: tensors (xtensor/BLAS), layers (dense,
convolutional, recurrent, attention, spiking LIF with surrogate gradients), optimizers,
training loops, signal processing (wavelets, LFCC), paraconsistent feature evaluation, and data
loaders for the bases the research uses. On top of it sit the experiments, the scripts that
turn their runs into papers, and the committed results.

**The documentation is the wiki: start at [`.wiki/Home.md`](.wiki/Home.md).** History of notable changes: [`CHANGELOG.md`](CHANGELOG.md). To find where a
change goes, use [How to Change Anything](.wiki/Guides/How-To-Change-Anything.md).

## Build and test

Requirements (CMake ≥ 3.28, a C++20 compiler, Ninja; the configure step installs the system
libraries on Ubuntu/Arch/macOS and fetches the rest): [Home › Requirements](.wiki/Home.md#requirements).

```bash
cd software/nn
cmake --preset=max-performance                          # configure (first time: several minutes)
cmake --build --preset=max-performance -j$(nproc)       # everything
ctest --test-dir out/build/max-performance --output-on-failure -j4
```

`ctest -R <name>` filters by **GoogleTest suite** name (`-R TensorOpsTest`), not by executable
name (`-R tensor_gtest` silently matches nothing). Other presets (debug, PGO, Python
bindings, macOS): [Build System](.wiki/Guides/Build-System.md).

## Layout

| Path | What | Docs |
|---|---|---|
| `include/` | public headers, backend-agnostic; include them without prefix: `"tensor/Tensor.hpp"`, `"layers/dense/Linear.hpp"` (there is no `include/nn/`) | [Architecture](.wiki/Architecture.md) |

## Experiments

Folders and targets are named after what each experiment is. Stored run tags still carry the
old numbers (`e05_…` is the thesis).

| Folder / binary | Was | What | Docs |
|---|---|---|---|
| `thesis` | 05 | **the thesis**: Phase 00 extractor ranking → Phase 01 authentication → BIOMEX-DB replication | [`README`](src/experiments/thesis/README.md), [Experiment05](.wiki/Experiments/Thesis.md) |
| `meeting01` | 04 | the conference paper: SNN-AE vs matched controls under nested leave-one-group-out | [`README`](src/experiments/meeting01/README.md), [Meeting01](.wiki/Experiments/Meeting01.md) |
| `paraconsistentGA` | — | NSGA-II search of autoencoder architectures ranked by `d_penalized` | [`README`](src/experiments/paraconsistentGA/README.md), [paraconsistentGA](.wiki/Experiments/ParaconsistentGA.md) |

Every experiment reads a JSON **profile** that declares every setting (there are no
defaults) and refuses anything it does not recognise. The thesis profiles are generated by a
script, never edited by hand.
